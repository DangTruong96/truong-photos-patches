# Bản vá Morphe cho Google Photos (bản cá nhân)

Bundle `.mpp` dựng sẵn cho Morphe Manager. Hỗ trợ Google Photos 7.97.0.997578476.

Thêm vào Morphe Manager: https://morphe.software/add-source?github=DangTruong96/truong-photos-patches

Nguồn gốc: Morphe Google Photos by Akash-Sriram (GPL-3.0). Chỉ dùng cá nhân.

Lưu ý: APK vá bằng Morphe Manager được ký bằng keystore trong Manager của bạn; APK vá sẵn do chủ repo gửi riêng được ký bằng keystore khác — với mỗi app, hãy chọn một đường và dùng nhất quán để các bản cập nhật cài đè được lên nhau.
